Práctica 4: Suma Consecutiva (Ciclo For vs. Fórmula de Gauss)

¿Qué se hizo?
Se construyó un programa que lee un número entero N, realiza la suma acumulada de todos los números desde el 1 hasta N utilizando un ciclo repetitivo for, hace la traza paso a paso, y finalmente compara ese resultado con el cálculo directo utilizando la fórmula matemática de Gauss.

¿Por qué se hizo de esta forma?
Variable acumuladora (suma = 0 y suma += i):Funciona como una "alcancía" numérica que va guardando y sumando el valor de la variable de conteo (i) en cada vuelta del ciclo.
Ciclo for (controlado por i <= n):Permite automatizar la repetición paso a paso, ideal para ver la traza exacta de cómo evoluciona el proceso de conteo y suma de manera secuencial.
Fórmula de Gauss ((n * (n + 1)) / 2):Se incluyó para demostrar el atajo matemático directo. Permite comprobar que la computadora llega exactamente al mismo resultado numérico (por ejemplo, 15 para N=5) de forma instantánea, mostrando la relación entre la programación y la eficiencia matemática.
